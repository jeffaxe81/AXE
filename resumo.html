Como interpretar o acompanhamento?

Percentual de marcos editoriais é a fração dos marcos cadastrados no portfólio que foram marcados como concluídos. Não corresponde ao percentual de código desenvolvido, ao total de testes aprovados nem à prontidão para produção.

CI registrada indica somente que o GitHub possui uma execução observada. Mesmo uma CI bem-sucedida não comprova testes funcionais ponta a ponta, homologação, licenciamento ou autorização de uso em produção.

Esta página não altera os projetos. Para a situação de liberação formal, decisões GO/NO-GO e histórico de evidências, consulte o painel de homologação. Se a coleta estiver atrasada ou indisponível, os números não serão apresentados como atuais.
